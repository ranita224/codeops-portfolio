**Banking System — Module 1 Portfolio**
**Overview**
This project is a simple banking system simulation built in Python. It demonstrates how to design classes, apply design patterns, and use algorithms like breadth‑first search (BFS).
The project was developed incrementally across multiple days, with each day adding new functionality.
**How to Run**
1.Clone the repository:
git clone <your-repo-URL>
cd <your-repo-folder>
2.Run the program:
python bank.py
